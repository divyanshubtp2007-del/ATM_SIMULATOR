# ATM SIMULATOR

## About the Project
ATM Simulator is a console-based application developed using C++. It simulates basic ATM operations and provides a simple banking experience.

## Features
- PIN Authentication
- Check Account Balance
- Deposit Money
- Withdraw Money
- Exit Option

## Technologies Used
- C++
- VS Code
- Git and GitHub

## Concepts Used
- Conditional Statements
- Loops
- Functions
- Variables
- Switch Case

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the C++ source file.
4. Run the generated executable.
